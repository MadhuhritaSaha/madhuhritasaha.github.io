# Madhuhrita Saha — Portfolio Website

A single-page portfolio (HTML/CSS/JS, zero dependencies) for Madhuhrita Saha —
final-year ECE undergraduate (VLSI · embedded systems · edge AI), published researcher
and formally trained painter from Kolkata, India.

## Files
- `index.html` — all sections & content
- `styles.css` — design system (navy / amethyst / orange / gold)
- `script.js` — interactions (typing hero, scroll-reveal, filters, lightbox, count-ups)
- `assets/` — optimized images (WebP) + résumé PDF

## Deployed on GitHub Pages
The site goes live at **https://madhuhritasaha.github.io**

(That's it — no Jekyll, no build step. `.nojekyll` is included so GitHub serves the files as-is.)
